# Ejercicio-6---Polimorfismo-via-Interfaces
Nombre Completo: María del Pilar Ordóñez Helton 
Carné: 26360

Administra las integraciones externas de una plataforma de comercio electrónico, como pasarelas de pago, 
proveedores de envíos y certificadores de facturación electrónica. Al iniciar, 
carga diez integraciones simuladas y ofrece un menú de consola para listarlas, consultar su configuración, 
ordenarlas por latencia, simular cobros y reintegros y generar facturas o guías de envío en XML. 
Si una integración no admite una operación, la solicitud se ignora sin interrumpir el programa. 
Su diseño utiliza interfaces y polimorfismo para facilitar la incorporación de nuevos proveedores sin modificar el motor principal.

Cómo ejecutar javac -d bin src/*.java java -cp bin Main
